Política de Privacidade do SOS Pet


1. Introdução

A Política de Privacidade do SOS Pet tem como objetivo informar os usuários sobre como coletamos, utilizamos, armazenamos e protegemos os dados pessoais fornecidos na plataforma, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD). Ao utilizar o SOS Pet, você concorda com as práticas descritas nesta política.

2. Dados Coletados

O SOS Pet coleta os seguintes dados pessoais dos usuários:

  • Dados de cadastro: Nome completo, e-mail, telefone, CPF e foto de perfil (opcional);
  • Dados relacionados aos animais: Espécie, nome, características físicas (porte, cor, raça), fotos claras e recentes, data e local onde o animal foi perdido ou encontrado;
  • Dados de uso: Informações sobre interações na plataforma, como buscas realizadas e contatos estabelecidos.

3. Finalidades do Tratamento de Dados

Os dados coletados são utilizados exclusivamente para as seguintes finalidades:

  • Facilitar a comunicação entre usuários que perderam seus animais e aqueles que os encontraram;
  • Divulgar registros de animais perdidos ou encontrados na plataforma;
  • Melhorar a experiência do usuário e o funcionamento da plataforma;
  • Cumprir obrigações legais ou regulatórias.

4. Compartilhamento de Dados

O SOS Pet não vende, aluga ou compartilha dados pessoais com terceiros, exceto nas seguintes situações:

  • Quando necessário para cumprir obrigações legais ou regulatórias;
  • Mediante consentimento explícito do usuário;
  • Para facilitar o contato entre usuários interessados em devolver ou encontrar animais perdidos.

5. Direitos dos Titulares de Dados

De acordo com a LGPD, os usuários têm os seguintes direitos em relação aos seus dados pessoais:

  • Acesso: Solicitar informações sobre quais dados estão sendo tratados e como são utilizados;
  • Correção: Solicitar a atualização ou correção de dados incompletos, inexatos ou desatualizados;
  • Exclusão: Solicitar a exclusão de dados, exceto quando a retenção for necessária para cumprir obrigações legais;
  • Portabilidade: Solicitar a transferência de dados para outro fornecedor de serviço, quando tecnicamente viável;
  • Revogação do consentimento: Revogar o consentimento para o tratamento de dados, quando este for a base legal para o tratamento.

Para exercer esses direitos, o usuário deve entrar em contato com o SOS Pet por meio dos canais de atendimento disponíveis na plataforma.

6. Segurança dos Dados

O SOS Pet adota medidas técnicas e organizacionais para proteger os dados pessoais dos usuários, incluindo:

  • Uso de sistemas de criptografia para proteger informações sensíveis;
  • Limitação de acesso aos dados apenas a pessoas autorizadas;
  • Monitoramento constante para prevenir violações de segurança.

7. Retenção de Dados

Os dados pessoais serão armazenados pelo tempo necessário para cumprir as finalidades descritas nesta política, exceto quando a retenção for exigida por lei. Após esse período, os dados serão excluídos ou anonimizados.

8. Alterações na Política de Privacidade

Esta Política de Privacidade poderá ser atualizada periodicamente para refletir mudanças nas práticas de tratamento de dados ou na legislação aplicável. Recomendamos que os usuários revisem esta página regularmente para se manterem informados. O uso continuado da plataforma após alterações implica na aceitação da nova versão da política.

9. Disposições Finais

Esta Política de Privacidade é parte integrante dos Termos e Condições Gerais de Uso do SOS Pet. Em caso de dúvidas ou conflitos, as disposições da LGPD e da legislação brasileira prevalecerão.

10. Agradecimento

Agradecemos por utilizar o SOS Pet e por contribuir para reunir animais de estimação perdidos com seus tutores!
